# My-Life-Dashboard
A personal life dashboard which could help build your personality.
📊 Life Dashboard - 个人成长量化系统
💡 项目初衷：我希望像游戏里的角色面板一样，量化个人的技能树、每日状态和阶段目标。迷茫时打开，就能知道自己有什么、缺什么、该往哪走。
⚙️ 技术栈：HTML5, CSS3, Python (Matplotlib/Pandas)
🚀 核心功能：前端卡片展示技能熟练度；Python自动处理数据生成成长曲线图。
🤖 开发模式：借助 AI 辅助编程，我负责架构设计与代码调试。
